# KALEESWARAN S | Cybersecurity Portfolio

A modern, high-performance cybersecurity portfolio built with **Next.js**, **Tailwind CSS**, and **Framer Motion**. This site serves as a central hub for my offensive security research, penetration testing projects, and real-time skill tracking.

## 🚀 Key Features

- **Project Gallery**: Modular showcase of security tools (EDR, Recon, SQLi detection).
- **Live Stats**: Real-time integration with **LeetCode** and **GitHub** activity widgets.
- **Certification Wall**: Interactive marquee featuring certifications from Packt, Linux Foundation, and more.
- **Dark Mode / Hacker Aesthetic**: Optimized for a premium, low-light security console experience.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
